概述

本文档记录金融 RAG Agent 项目的完整需求待办列表，包含 4 个 Epic 和 15 个 User Story。优先级基于价值-风险矩阵确定，并已规划第一个虚拟冲刺（Sprint 1）。所有 Story 均可独立测试与交付。
Epic 1：金融问答核心能力

描述：构建一个能够准确检索金融法规知识、生成真实可信回答，并在无法回答时正确拒答的 RAG 问答引擎。
完成标准：

    向量库已加载全部经过校验的法规文档，支持相似度检索（k=2）

    对于事实查询，回答的忠实度 ≥ 0.8，关键数字完整率 ≥ 0.9

    对于知识库未覆盖的问题，拒答率达到 ≥ 0.95，误拒率 ≤ 0.05

    端到端响应时延 P95 < 2000ms

    核心逻辑已封装为 FinancialRAGSkill，并提供 run_with_context() 接口
